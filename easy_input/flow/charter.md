# 项目宪章 (charter)

> 立项填。所有 Agent 开工要读的第一份。

- **项目名**: EasyInput (多子项目总控仓库)
- **目标**: 构建围绕 ESP32-S3 的智能硬件输入生态系统，统一协调与管理固件开发、硬件设计以及 ESP-IDF 编译工具链。
- **范围**:
  - 做:
    - 总体项目里程碑协调与版本演进管理
    - 协调子项目之间的软硬件接口规范与通信协议契约 (`docs/contracts/`)
    - 统一工具链与环境构建配置 (`eim_config.toml`、EIM CLI、ESP-IDF v5.5.5)
    - 沉淀多 Agent 协作工作流、决策与跨模块踩坑经验
  - 不做:
    - 侵入或替代各子项目的独立 Git 版本流与底层具体实现
    - 引入私有凭证、设备私钥或破坏开源脱敏边界
- **约束**:
  - 核心硬件：EasyInput V2.0 / ESP32-S3
  - 固件环境基线：ESP-IDF 5.5.5
  - 单仓多子项目协作规范：根目录唯一控制面 (`flow/`) + 集中内容层 (`docs/`)
- **成功标准**:
  - 固件子项目 `easy-input-maker` 宿主测试 (`host_test`) 与硬件编译 (`idf.py build`) 稳定通过
  - 硬件规范 `easyinput-board-cy` 与固件引脚、电源定义一致且受契约保护
  - 开发者通过统一的文档与工具链配置即可实现环境搭建、固件构建与调试
- **角色**: 拍板 = 开发者 / 协作 = AI Agents (Claude Code / Codex / Antigravity)
