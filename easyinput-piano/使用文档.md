## 一、项目简介

**EasyInput Piano** 是基于 **EasyInput V2.0 开发板（ESP32-S3）** 制作的独立 8 键智能电子琴。
- **纯算法实时合成**：基于高保真谐波声学建模（基频 + 泛音 + ADSR 指数包络），无需外挂庞大的音频文件，声音清脆悦耳。
- **8 复音并发**：支持多键同时按下（和弦演奏），各音独立衰减互不掐断。
- **大声饱满输出**：满幅驱动 MAX98357A 3.2W Class-D 功放与板载扬声器。
- **软硬件一体**：开发板可脱离电脑独立演奏；连接电脑后支持赛博朋克网页控制台（Web Serial 直连），具备音符瀑布流、按键动画与通关烟花特效。

## 二、硬件接口与键位映射

EasyInput 开发板上的 8 个按键在物理上呈 **4×2 双排矩阵** 排布。本项目采用符合双手弹奏人体工学的**双排升序**映射：

```text
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│   S1: 5 (Sol)   │   S2: 6 (La)    │   S3: 7 (Si)    │  S4: i (高音Do) │  <- 上排 (高音区)
├─────────────────┼─────────────────┼─────────────────┼─────────────────┤
│   S5: 1 (Do)    │   S6: 2 (Re)    │   S7: 3 (Mi)    │  S8: 4 (Fa)     │  <- 下排 (基音区)
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

### 2. 其他板载硬件
- **旋转编码器**：顺时针旋转增大音量，逆时针旋转减小音量（0% ~ 100%）。
- **编码器按压键 (S9)**：短按一次循环切换演奏模式。
- **5 颗 WS2812 RGB LED**：实时反馈当前音高色彩、跟弹目标灯、音量柱状图与通关彩虹动效。
- **扬声器功放**：MAX98357A（I2S 接口），由 GPIO8 受控延迟上电，保障硬件安全。

## 四、三大运行模式详解

短按编码器旋钮，可在以下三大模式中依次循环切换：

### 模式 1：一键魔法自动演奏模式（开机默认）
- **自动弹奏**：开发板内置精确时钟，开机后**自动连续演奏整首《小星星》**，声音洪亮清晰。
- **灯光舞动**：5 颗 RGB 彩灯随着旋律跳动。
- **人机互动伴奏**：在板子自动弹奏的过程中，随意拍打板上的任意按键，会混入即兴和弦伴奏。
- **自动循环**：演奏完整首 42 个音符后，播放庆祝灯效并稍作停顿，接着循环进入下一轮。

### 模式 2：小星星跟弹教学模式 (Guide Practice)
- **目标指引**：网页端大字显示当前音符与歌词；板载 RGB 灯对应位置呼吸发光，提示该按哪个键。
- **纠错推进**：按对目标按键后发声并推进到下一个音；按错键会提示重试，不会扰乱曲调节奏。
- **通关庆典**：42 个音符全部弹奏正确后，开发板与网页端同步触发欢庆彩虹特效。

### 模式 3：自由琴键演奏模式 (Free Play)
- **独立电钢琴**：像一台真正的 8 键电子琴一样弹奏，支持多键齐按（和弦演奏）。
- **敲击即响**：按下击弦发音，松开自然阻尼，伴随专属音阶彩虹光芒。

## 五、炫酷网页端使用指南

为了告别枯燥的黑底白字终端，工程配套了高颜值的 **Web 控制台**：

### 1. 一键启动
进入 `easyinput-piano` 目录，直接双击运行：
👉 **[`启动网页端.bat`](file:///c:/Users/27200/Desktop/esay_input_pianokeys/easyinput-piano/%E5%90%AF%E5%8A%A8%E7%BD%91%E9%A1%B5%E7%AB%AF.bat)**

系统会自动打开 Chrome 或 Edge 浏览器并载入控制台页面。

### 2. 连接开发板
1. 确保开发板已通过 USB 数据线连接电脑且处于开机状态；
2. 点击页面右上角的 **【🔌 连接开发板 (Web Serial)】** 按钮；
3. 在浏览器弹出的端口列表中，选择你的设备（如 `USB JTAG/serial debug unit (COM3)`），点击“连接”；
4. 状态变为绿色的 **“已连接 EasyInput”** 即代表连接成功。

### 3. 网页端功能特色
- **虚拟 3D 琴键**：板子上按物理键，网页端对应琴键实时下沉发光！用鼠标点击或电脑键盘按数字键 `1~8` 也可以直接在电脑上弹奏。
- **音符卡片流**：全曲 42 张音符卡片横向平滑滚动，当前音符脉冲放大高亮。
- **实时进度条**：显示已弹奏音符数与完成百分比。
- **全屏烟花庆典**：全曲弹完时，网页自动绽放礼炮纸屑与烟花。

## 六、固件编译与烧录步骤

如果你修改了代码或需要重新烧录固件：

### 步骤 1：打开 ESP-IDF 终端
双击电脑桌面上的 **`IDF_v5.5.5_Powershell`** 快捷方式。

### 步骤 2：进入下载模式
1. 确保开发板电源开关处于 **【ON】（开机）** 状态；
2. **短按一下板子上的 BOOT 按键并松开**（进入芯片 ROM 下载等待状态）。

### 步骤 3：一键烧录
在打开的终端窗口中执行：
```powershell
cd C:\Users\27200\Desktop\esay_input_pianokeys\easyinput-piano
idf.py flash monitor
```
*(系统会自动识别连接的 COM 端口并烧录，无需手动输入端口号)*

### 步骤 4：重启开机
烧录完成后（提示 `Hash of data verified`），开发板停留在下载状态：
👉 **只需将开发板电源开关拨到 OFF，等 1 秒后再拨到 ON 重新开机即可！**

## 七、常见问题与排查 (FAQ)

### Q1: 运行 `idf.py` 提示找不到命令？
- **原因**：打开的是普通 PowerShell，未载入 ESP-IDF 环境变量。
- **解决**：请务必从桌面的 **`IDF_v5.5.5_Powershell`** 快捷方式打开，或者在当前终端输入：
  ```powershell
  . C:\Espressif\tools\Microsoft.v5.5.5.PowerShell_profile.ps1
  ```

### Q2: 烧录时报错 `No serial ports found` 或 `Could not open COMx`？
- **原因 1**：Type-C 数据线不支持数据传输（仅充电线）。请更换支持数据传输的 USB 线。
- **原因 2**：板子没有进入下载模式。请确保在**开机状态下短按一次 BOOT 键并松开**。
- **原因 3**：命令行中直接写了 `COMx`。直接执行 `idf.py flash monitor` 即可自动扫描。

### Q3: 烧录完停在 `waiting for download` 不动？
- **原因**：这是正常现象。烧录完成后 ESP32-S3 还停留在 ROM 下载模式中。
- **解决**：只需**把开发板电源开关关闭再打开（重启一次）**，板子就会立刻退出下载模式并启动钢琴程序。

### Q4: 烧录钢琴项目后，原先的 Beatbox 鼓机会损坏吗？如何切回？
- **完全不会损坏任何原有源码与硬件**！原先的项目源码完好无损保存在 `easyinput-beatbox` 目录中。
- 若想切回原本的鼓机，只需在终端中执行：
  ```powershell
  cd C:\Users\27200\Desktop\esay_input_pianokeys\easyinput-beatbox\firmware
  idf.py flash
  ```
  烧录后关开一次电源，开发板即刻还原为原来的鼓机/节拍器。
